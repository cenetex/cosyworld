# CosyWorld Storybook

`The World That Remembered` is a children’s picture-book guide to CosyWorld.
It explains avatars, items, locations, and emergent stories through one real
living-world simulation.

## Evidence used by the book

- The strict Cottage Pact proof passed with 8 reachable rooms, 3 repeatable
  care loops, and no dead rooms.
- Six playable worldpack compositions opened and replayed successfully.
- The living-world run moved the Dewbright Button to Gust and the Watch Bell
  to Skull.
- The run observed the Moonlit Trail project complete, discovered the Old Oak,
  Lost Woods, and Quiet Abbey, found Moonwool Thread, and returned to the
  Rain-Soft Garden.

The illustrations use Rati as the picture-book guide. The real run created a
fresh traveller, so the book says clearly that Rati stands in for that traveller
in the retelling.

## Story style

Use simple read-aloud language. Begin with care, name exact things and places,
show where an item moved, keep wonder safe and strange, and end with a place or
relationship the next visitor can meet.
