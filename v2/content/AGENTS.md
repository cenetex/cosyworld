# Identify the owning game before editing content

For current card-game work, follow `v2/worlds/card-table.json` and its selected
`card-world.json` sources. The forest catalog, shared avatars, base character
profiles, and compiled card packs live in `v2/card-game/`.

Classic `actors.json`, `registry.json`, and official world bundles describe
compatibility content. Use them for an explicit classic task. Preserve source
pack IDs and compile generated files through their owning builder.

Read `docs/current-game.md` for the current source map.
