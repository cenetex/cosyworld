# Scene art

## Wooden-box card back (2026-10-31)

`card-back.webp` is the approved closed wooden-box lid, made with the built-in
image tool. Oak branches, roots, moths and bells surround a dark central inset.
The 1024 × 1536 opaque WebP preserves the generated composition without cropping
and stays below 300 KB. The image pipeline supplies its 512 × 768 phone copy.

[The art prompts](card-back-art-prompts.json) preserve the full generation prompt
and its sources. [The provenance manifest](card-back-provenance.json) records
the generation ID, original PNG hash, runtime hashes and encoding settings.
The original generated PNG is represented by its hash.

## Personal buttons (2026-10-30)

The eight `lonely-forest/button-<traveler>.png` sprites supply the artwork for
[the personal button and scarf quest](https://github.com/cenetex/cosyworld/issues/1441).
Each is one centered wooden sewing button, with four visible thread holes,
worn paint in the traveler's own colour, and a cross stitch in the complementary
scarf colour. Vale's black button is the reference for the seven colour edits.

| Traveler | Button | Thread |
| --- | --- | --- |
| Vale | Charcoal black | Warm ivory |
| Mara | Crimson red | Sage green |
| Ash | Burnt orange | Dusty blue |
| Nell | Mustard yellow | Lavender violet |
| Tavi | Moss green | Brick red |
| Rue | Cobalt blue | Apricot orange |
| Orin | Indigo blue-violet | Amber gold |
| Ada | Violet | Pale warm yellow |

The built-in image tool generated each sprite with transparent surroundings
and open holes. Runtime PNGs are deterministically resized to the specification's
1024 × 1024 canvas with Sharp's Lanczos3 filter. The image pipeline produces
1024px stage and 512px card WebPs with matching alpha at each size.
`public-assets.mjs` publishes the canonical item paths, which the prepared
quest items can reference directly.

[The button manifest](lonely-forest/button-provenance.json) records generation
IDs, available prompts and prompt summaries, source and runtime hashes,
dimensions, normalization settings and alpha checks. The selected generated
originals are represented by their hashes; the normalized PNGs are the runtime
sources. [The gallery](../../../docs/art/button-gallery.png) shows the full set
against light and dark surfaces at card scale.

## Player scarves and attic variants (2026-10-30)

The eight `shared/characters/*-scarf.png` images are individual edits made with
the built-in image tool. Each uses its established character painting as the
reference, preserving the face, pose, empty hands and painted style. The scarf
uses the character's complementary colour and its sewn button uses the primary
colour. These pairs follow `v2/docs/card-table/art-prompts.json`:

| Character | Primary colour and button | Scarf |
| --- | --- | --- |
| Vale | Black | Ivory |
| Mara | Crimson red | Sage green |
| Ash | Burnt orange | Dusty blue |
| Nell | Mustard yellow | Violet / lavender |
| Tavi | Moss green | Brick red |
| Rue | Cobalt blue | Apricot orange |
| Orin | Indigo blue-violet | Ochre yellow |
| Ada | Violet | Pale yellow-green |

The shared cast keeps the plain portraits as each traveler's artwork. The
stage, cards, speaker portrait and player list switch to the scarf painting
only while that traveler holds their own scarf item, `forest-scarf-<id>`
(`scarves.mjs`); the picker stays plain. Vale's variant uses the established
black-clothed shared portrait as its reference. The paintings add no rules of
their own. All eight runtime PNGs preserve their selected
generated bytes and alpha at 1024 × 1536. Ada received a separate framing edit
to keep the complete wheelchair inside clear margins.

`shared/places/attic-dark.webp` leaves the mirror empty in an unlit attic.
`shared/places/attic-stairs.webp` shows the lit descent to Cosy Cottage while
retaining the Black Pond mirror. Both edit `attic.png`. Their runtime WebPs
decode pixel-for-pixel to the generated opaque PNGs. The dark image is
1671 × 941; the stairs image is 1672 × 941. Neither was resized. The existing
`cloth` item ID remains stable in the attic's route rules.

[The provenance manifest](shared/scarf-attic-provenance.json) records all exact
prompts, including Ada's framing correction, reference hashes, generation IDs,
selected source PNG hashes, runtime hashes, dimensions and alpha checks. Source
backdrop PNGs are represented by their hashes rather than duplicated here.

## Steam Clock opening (2026-10-19)

`badger-forest/steam-clock-background.png` (1536 × 1024, RGB),
`badger-forest/badger-sleeping.png` and `badger-forest/badger-grumpy.png` (both
1254 × 1254, RGBA) were made with the built-in image tool for this opening.
They live in the `badger-forest` world pack's asset folder. These files preserve the generated PNGs and alpha.

The references are the original CosyWorld images
`v2/content/lonely-forest/assets/characters/slices/18-forest-clock-shrine.png`
and `13-badger-cub.png`. The user identified image 13 as Grumpy Badger.

Background direction: preserve the old dark Steam Clock on its mossy stone
base, with warm dappled woodland light and a clear patch of ground beside it.
Character direction: keep Badger's broad striped face, round belly, heavy
paws, and painted fur. The first pose sleeps sitting up. The second uses
the sleeping cutout as its reference, with open eyes and comic irritation.
Both poses use a transparent background and the same framing.
