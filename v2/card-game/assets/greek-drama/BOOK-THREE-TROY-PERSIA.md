# Book III portraits: Troy, Thrace and Persia

Six full-body adult portraits follow the Book III source plan.

| File | Planned actor binding |
| --- | --- |
| `book-three-hecuba.png` | `greek-troy-hecuba` and `greek-thrace-hecuba` |
| `book-three-andromache.png` | `greek-troy-andromache` |
| `book-three-polyxena.png` | `greek-thrace-polyxena` |
| `book-three-atossa.png` | `greek-susa-atossa` |
| `book-three-xerxes.png` | `greek-susa-xerxes` |
| `book-three-talthybius.png` | `greek-troy-talthybius` |

Hecuba uses one canonical elderly face in both chapters. Andromache has a
distinct mature face. Both wear plain travel and mourning clothes. Polyxena
is a clearly grown adult. Talthybius is an adult herald with a clear face.
Atossa wears a long-sleeved woven Persian court robe. Xerxes wears Persian
travel clothes and a worn return cloak. The two Persian portraits belong to
the separately named historical Salamis account.

Each image shows one living adult with empty hands. Children and offstage
deaths remain in the spoken source account. Chapter actions own the separate
cloth, cloak, shield and message items.

The built-in image generation tool made every portrait. The PNG files keep
their original generated pixels and native transparent alpha.
`book-three-troy-persia-provenance.json` records full prompts, source-plan
hashes, actor bindings, style references, dress research links, generated
source names, dimensions, source and output hashes, alpha measurements and
review backgrounds. Clothing and faces are painted interpretations for the
game. The museum sources guided the broad Persian garment shapes.

## Review and handoff

All six portraits are 1024 by 1536 pixels. The source and output hashes match
byte for byte. Native alpha and visible
margins are checked on all six images. Full heads, hands, hems and both feet
fit within each original canvas.

Three browser sheets pair Hecuba with Andromache, Polyxena with Talthybius,
and Atossa with Xerxes. Each sheet shows day and night overlays at desktop
width and in a 390 by 580 phone view. Approved Greek paintings provide the
review light settings. Chapter stage bindings belong to the source owner.

This art draft targets `codex/greek-book-iii`. The chapter owner will bind the
exact image paths and native left-facing metadata, build optimized variants,
update public assets, and run full game checks with the final chapter source.
