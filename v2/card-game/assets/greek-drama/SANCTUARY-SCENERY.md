# Cithaeron and Argive sanctuary scenery

These four paintings cover two places in the Greek chapter plan.

| File | Place and light |
| --- | --- |
| `bacchae-cithaeron-day.webp` | Cithaeron Slopes in daylight |
| `bacchae-cithaeron-night.webp` | The same wooded slope at night |
| `suppliants-argive-shore-day.webp` | Argive Shore Sanctuary in daylight |
| `suppliants-argive-shore-night.webp` | The same coastal sanctuary at night |

## Cithaeron Slopes

Place: `greek-cithaeron`. Work: `euripides-bacchae`.
The detailed plan is in `docs/worldpacks/greek-epic-loom/euripides.md`.
The current place describes goat paths, a wooded slope, and a distant drum.

The painting has a broad rock-and-earth clearing for the cast. An uphill path
passes a tall fir and climbs the rugged wooded slope. A second path turns down
toward the Theban valley. Oaks, pines, ivy, limestone, and a small ribboned stone
give the place its mountain setting. The night partner keeps the same layout.

## Argive Shore Sanctuary

Place: `greek-argos-sanctuary`. Work: `aeschylus-suppliant-women`.
The detailed plan is in `docs/worldpacks/greek-epic-loom/tragedians.md`.
The current place describes suppliant branches, a coastal altar, and an
approaching ship.

The painting has an altar, olive branches bound with wool, a small shrine, and
an open court for the cast. An open gate leads toward the town's sheltered
doorways. The sea and a small distant ship sit beyond the court. The gate and
path are placed near the center for the phone crop. The night partner keeps
the same altar, branches, court, gate, path, shore, and ship.

## Sources and chapter handoff

The original PNGs are kept in `sanctuary-sources/`, including the first Argive
day painting and its gate-layout edits. The WebPs keep the full source size and
use quality 94. `sanctuary-scenery-provenance.json` records all prompts,
references, generation names, dimensions, hashes, and processing.
The built-in image generation tool made the paintings and edits.

## Review

All four stages are 1672 × 941 pixels. Each saved source PNG matches its
generated file byte for byte. The output and reference hashes were checked.
The night views were reviewed beside their day views for matching layout.

Two browser review sheets show each pair at full width and in a central
390 × 580 phone crop. Cithaeron keeps its clearing and uphill path visible.
The Argive crop keeps the altar, branches, sea, open passage, and a sheltered
doorway visible. Both foregrounds have room for the cast.

The chapter owners will add catalog bindings, daylight registration, optimized
variants, public asset generation, shared rules, and final release versions.
