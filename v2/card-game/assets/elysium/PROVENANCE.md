# Elysium: card art

The first Elysium images come from the art proposal in
`docs/art-direction/worldpacks/review-trios/`, with prompts recorded in that
folder's `builtin-receipts.json`. The Spiral, Observatory, and Star Chart are
dedicated illustrations made with the built-in image tool for the observatory
route. The repository's [MIT license](../../../../LICENSE) applies.

| File                       | Source                           | Treatment                                                                                        |
| -------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------ |
| `void-001.png`             | `elysium-location.png`           | Copied unchanged (1672 × 941).                                                                   |
| `gold-spiral.png`          | Dedicated generation             | Full 16:9 terrace and suspended spiral with a broken filament.                                   |
| `gold-spiral-open.png`     | Edit of `gold-spiral.png`        | The filament reaches the terrace while the bridge is open.                                       |
| `observatory.png`          | Dedicated generation             | Full 16:9 terrace with a bronze armillary.                                                       |
| `star-chart.png`           | Dedicated generation             | Folding bronze chart on a transparent 1254 × 1254 canvas.                                        |
| `keystone-ledge.png`       | `references/elysium-concept.png` | The board's main scene, with the figure painted out, cropped to 16:9 and scaled to 1672 × 941.   |
| `keystone-ledge-empty.png` | `keystone-ledge.png`             | The same scene with the obsidian stone painted out, leaving its plinth.                          |
| `resident.png`             | `elysium-avatar.png`             | Black paper keyed to transparency, set on a 1024 × 1536 RGBA canvas.                             |
| `wayfinder.png`            | `elysium-item.png`               | Black paper keyed to transparency, framed on a 1254 × 1254 RGBA canvas.                          |
| `keystone.png`             | `references/elysium-concept.png` | The board's obsidian stone study, keyed to transparency and framed on a 1254 × 1254 RGBA canvas. |

The ledge and keystone images are cut from larger images. If you replace
either with a dedicated generation, keep the file name.
