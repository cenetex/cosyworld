# Rest-bound Journal pages

This earlier multi-leaf prose design has been replaced by
[Daily Journal Images](journal-storybook-pages.md).

The current contract keeps short-rest updates hidden and publishes at most one
first-person generated Journal-page image per avatar and UTC day, on that
avatar's first long rest. The player-facing Journal contains no live event log,
open leaf, prose rows, meters, spreadsheets, or room-memory panels.
