# Storybook plates

Watercolor reference plates of the live cast, kept from the retired
`storybook/` explainer, "The World That Remembered" (#936, `71ecebb5`). They
illustrate one real living-world run and serve as reference art for the
read-aloud retelling in
[the world chronicle](../../../archive/backlog/player-journal-semantic-chronicle.md#world-chronicle).

| File | Shows |
|---|---|
| `rain-soft-garden.webp` | Rati, a mouse in a green apron and blue scarf, finds a pearly button under a wet leaf while Gust, a tiny cloud gremlin, watches. |
| `watch-bell-home.webp` | Rati gives a small brass bell to Skull, a very large charcoal wolf, beside the Cottage hearth. |
| `moonlit-trail.webp` | Rati steadies rings of pale moonlight while a mouse-shaped reflection called Coach mirrors the pose. |
| `moonwool-home.webp` | Rati carries a glowing silver thread from the Quiet Abbey, through the Lost Woods, and under the Old Oak. |
| `social-card.jpg` | An open storybook, button, bell, moonlit path, glowing thread, and lantern. |
