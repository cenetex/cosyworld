# Name the quest when a player gives it up

The card table names the goal in the action text and the saved caption. For
example, “Vale abandons their quest to meet Pip.” Simple person quests say
“meet.” Other quests use the same goal text as the quest card.

The journal still records the same Drop action. The new rules bundle stores the
new caption. Older bundles keep the caption that their version wrote. The text catalog
accepts that earlier caption when players import older saves.
