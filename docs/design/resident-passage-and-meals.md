# Personal passage and a resident's meal

A pack resident can grant passage with `passWhen`. Each condition reads the
traveller taking the step. `trusted` requires the stated trust and no active
grievance toward that traveller. The guard keeps its post while permitting
one traveller. An invited companion needs its own passage.

A resident carrying a meal follows the place named by its Eat or Drink
quest. Its existing movement, range, duty and consent rules still apply.
The planner chooses ordinary legal actions, which the shared host commits.

This prerequisite supplies the general rules for the later Greek paper
change. Focused source tests cover personal passage, grievances, companion
access and a meal journey. A native shared-host test checks the same passage
boundary. Fresh shared rules keep every earlier bundle fixed for replay.
