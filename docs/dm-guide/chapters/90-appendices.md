# Appendices {#appendices}

## Appendix A: One-Page Referee Procedure {#appendix-referee}

::: {.referee}
**STATUS NOTE.** Authority, two-action presentation, played time, sanctuary,
and no-roll certainty are Core. Unified discovery, typed obstacles, no-null
commitments, recovery proof, and navigation cairns are Accepted Targets.
Fatigue and short-rest limits apply only during their Playtest.
:::

### On arrival

1. State the place and its safety.
2. Describe obvious sensory facts and Hazard Tells.
3. Name present residents, objects, exits, and local pressure.
4. Show two suggested actions.
5. Keep the complete legal set reachable through All Actions.

### Before commitment

1. Confirm intent, target, and method.
2. State requirements, time, and resource cost.
3. Warn of important consequences.
4. Roll only if real uncertainty and consequence remain.

### After commitment

1. Resolve through authoritative rules.
2. Apply state changes and one-time claims.
3. Freeze any table receipt.
4. Narrate only certified facts.
5. Update public memory and the Journal.
6. Present the changed action set.

### Never

- hide an obvious Hazard Tell;
- reroll established hidden truth;
- roll for certain exact-key use;
- return an unchanged failure;
- let AI or a client create authority;
- advance pressure through wall-clock delay;
- remove every recovery route;
- treat a cairn as shelter or sanctuary.

## Appendix B: Discovery Quick Reference {#appendix-discovery}

::: {.target}
**ACCEPTED TARGET.** This table summarizes the unified discovery language.
Current Search, Study, and Scout have narrower shipped meanings; current Scout
reveals one prepared adjacent segment without movement.
:::

```text
Latent -> Signed -> Lead -> Revealed -> Accessible -> Secured
```

| Action         | Function                                                    |
| -------------- | ----------------------------------------------------------- |
| Scene Notice   | Free obvious facts and Tells                                |
| Focused Notice | Examine one subject and expose an actionable Sign           |
| Search         | Exhaustively resolve one local physical target              |
| Study          | Interpret known evidence, pattern, provenance, or mechanism |
| Scout          | Pursue a geographic Lead from an Anchor or active foray     |
| Travel         | Move along a known accessible route                         |
| Open           | Change a Gate state                                         |
| Take           | Transfer an accessible item after capacity checks           |
| Mark           | Preserve a temporary return cue for the active foray        |
| Build cairn    | Make a traversed return leg durable for later branching     |

Mark, Build cairn, and anchored forays are Accepted Target traversal, not
current runtime behavior.

## Appendix I: Publication Proof Checklist {#appendix-checklist}

### Authority

- [ ] Every authoritative change has one owner.
- [ ] AI and client presentation cannot mutate state.
- [ ] Every table uses stable inputs and a version.
- [ ] Every one-time effect has an idempotent claim.
- [ ] Replay restores identical identities and results.

### Discovery and obstacles

- [ ] Every required discovery has a finite Sign budget.
- [ ] Required objects are fixed or guaranteed.
- [ ] Repetition cannot reroll hidden truth.
- [ ] Reveal, access, and custody remain distinct.
- [ ] Every Hazard has a Tell.
- [ ] Every important Gate has a return contract.
- [ ] Exact safe methods do not roll.
- [ ] Every risky failure changes the situation.
- [ ] Access scope is explicit.

### Expedition and shared world

- [ ] For Scout v2 content, every branch traces back to an Anchor.
- [ ] For Scout v2 content, cairns stabilize navigation but do not grant Rest.
- [ ] Pressure advances only through committed relevant play.
- [ ] Flee or withdrawal is a real outcome.
- [ ] When the Fatigue Playtest is active, maximum Fatigue preserves recovery.
- [ ] Removed keys do not deadlock required content.
- [ ] Unique items cannot duplicate under concurrency.
- [ ] Taken loot does not silently restock.
- [ ] The seventh visit remains meaningful or honestly quiet.

### Presentation

- [ ] Obvious facts are free.
- [ ] Costs and serious consequences precede commitment.
- [ ] Journal prose describes meaning, not implementation.
- [ ] Deterministic fallback copy is complete.
- [ ] The adventure remains playable without AI.
