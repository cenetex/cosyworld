The Elysium resident uses source actor `289553007952`, whose authored name is
`Anthropic: Claude Fable Latest`. Its silver appearance is a design proposal.
The model binding stays in the authored source. The Wayfinder is an existing
resolved loot identity.

The [manifest](manifest.json) records the 18 selected subjects and output hashes.
The [Replicate records](replicate-receipts.json) hold the pinned model versions,
full inputs, seeds, prediction IDs, and hashes. They include one earlier net-cord
study. The [built-in records](builtin-receipts.json) hold the prompts and hashed
references. Their exact provider model version is unavailable from the tool.
The earlier Elysium and Lantern style boards are saved in `references/`.

All samples await visual approval. These are raw outputs. Small generated marks,
the charm's surface treatment, and character details remain part of the art
review. The next art pass can use approved samples as its references.
