# CosyWorld items and progress

The current card game records item custody, trades, gifts, quest collections,
experience, and levels in its saved world. Shared play commits those changes
through the server rules and journal. The [current source map](docs/current-game.md)
identifies the owning game modules and catalogs.

Use the current item, motive, quest, and shared-world rules to establish the
cost and effect of a card action. Provider costs belong to the server's operating
budget. Treat future economy proposals as planning until their rules ship.

The classic Orb economy, linked-avatar adapters, and NFT migration records are
documented in the [classic economy archive](docs/archive/classic/ECONOMY.md).
That guide supports compatibility and audit work on those systems.
